# FoxPoint

Стартовый монорепо-каркас проекта "Интернет, как раньше" под VPS-развёртывание.

## Что уже есть

- `apps/api` — общий backend для сайта, будущего Telegram-бота и админки.
- `apps/web` — публичная главная, вход, каркас ЛК и каркас админки.
- `packages/db/prisma/schema.prisma` — стартовая схема БД по ТЗ.
- `docker-compose.yml` — локальный и VPS-friendly запуск с `postgres`, `api`, `web`.

## Почему такая структура

По ТЗ сайт и Telegram-бот обязаны работать через единый backend и единую БД. Поэтому каркас разделён на:

1. API-слой с доменной моделью и проверками.
2. Web-слой для гостевой части, ЛК и админ-панели.
3. Отдельную схему БД, которую потом можно мигрировать без переписывания фронтенда.

## Быстрый старт

1. Скопировать `.env.example` в `.env`.
2. Установить зависимости:

```bash
npm install
```

3. Сгенерировать Prisma client:

```bash
npm run db:generate
```

4. Запустить Postgres через Docker:

```bash
docker compose up -d postgres
```

5. Поднять проект в dev-режиме в двух терминалах:

```bash
npm run dev:api
npm run dev:web
```

Или поднять сразу контейнерами:

```bash
docker compose up --build
```
