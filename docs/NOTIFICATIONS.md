# Уведомления в личном кабинете

Колокольчик «Уведомления и входы» получает события из базы и обновляется каждые 5 секунд, пока вкладка видима. Новые входы, завершения сессий, каждый ответ поддержки, изменение статуса обращения, подтверждение оплаты и изменение заказа создают уведомление в той же транзакции, что и само событие. Текст ответа и сведения о входе сохраняются в `Notification.payloadSnapshot`, поэтому последующие изменения не переписывают историю.

Ответ открывает конкретное обращение. Можно прочитать одно уведомление или весь список, а затем очистить его без перезагрузки страницы. Очистка скрывает события до момента полученного снимка списка; сообщения поддержки и сессии сохраняются. Уведомления, пришедшие после этого момента, остаются новыми. Счётчик и массовые действия охватывают все события, даже когда показаны только последние 50.

При первом чтении списка существующие входы (по `createdAt`, а не активности `lastSeenAt`) и ответы поддержки добавляются из истории: до 20 последних входов и 30 ответов. Ранее очищенные события исключаются, ранее прочитанные сохраняют статус. Повторная проверка истории выполняется не чаще раза в минуту и не создаёт дубликаты.

API `/api/me/notifications`, `/read`, `/clear` проверяет подписанную действующую клиентскую сессию и ограничивает все действия владельцем. Веб-прокси дополнительно проверяет Origin для изменений и запрещает кэширование. При ошибке соединения список сохраняется и появляется сообщение об ошибке.

Изменение схемы добавляет только необязательное JSON-поле. Обычный локальный деплой выполняет `prisma db push` после резервной копии кода и базы.

Интеграционная проверка использует отдельную PostgreSQL-базу с актуальной схемой и именем, содержащим `notifications_test`:

```powershell
$env:NOTIFICATIONS_TEST_DATABASE_URL = 'postgresql://postgres@127.0.0.1:55433/foxpoint_notifications_test?schema=public'
npm run test:notifications
```

Тест создаёт и удаляет только свои аккаунты. Он проверяет реальные ответы/входы/оплаты/заказы, сохранение текста, восстановление истории, изоляцию аккаунтов, отзыв сессии, параллельные ответы, счётчик свыше 50 событий и новые уведомления во время чтения/очистки.
