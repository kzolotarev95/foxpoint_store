# Ресурсы VPS в админ-панели

На главной странице админки рядом с **Управление сервисом** показаны три мини-виджета:

- **ЦП** — общая загрузка процессора сервера в процентах и число логических ядер.
- **ОЗУ** — занятая оперативная память в процентах, объём занятой и общей памяти.
- **Диск** — доступное место и общий объём системного диска. Полоска показывает занятое место.

Данные запрашиваются каждые 3 секунды без перезагрузки страницы. Неактивная вкладка приостанавливает запросы; при возвращении показатели обновляются сразу. При потере связи предыдущие значения помечаются как устаревшие, а время последнего измерения остаётся видно. Отказ одного счётчика не скрывает другие показатели.

На Windows при локальном просмотре виджеты показывают ресурсы компьютера и имеют подпись **Ресурсы · локальный компьютер**. После установки на VPS измерения выполняются процессом API непосредственно на сервере. Дополнительные агенты мониторинга не требуются.

ЦП измеряется по разнице системных счётчиков всех ядер за 500 мс. Для Linux ОЗУ рассчитывается через `MemAvailable` из `/proc/meminfo`, учитывая доступный для повторного использования кеш. Свободный диск рассчитывается из `bavail × bsize` системного раздела `/` через `statfs`. Это диск всего сервера, включая файлы панели и бэкапы на том же разделе; отдельные дополнительные диски не суммируются.

API `/api/admin/server-metrics` и веб-маршрут `/admin/server-metrics` требуют подписанную сессию администратора, включая запросы через localhost. Ответы не кешируются браузером. На сервере измерения кешируются на 2 секунды, а одновременные запросы нескольких вкладок используют один замер.

Проверка: `npm run test:server-metrics`. Она проверяет расчёты, Linux-кеш памяти, одновременные запросы, истечение кеша, частичные отказы, авторизацию и настоящие системные показания.

Локальная установка на VPS без пуша из Windows PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\k.zolotarev95\Documents\FoxPoint\scripts\deploy-local-fix.ps1"
```

Скрипт сохраняет текущую версию панели и дамп БД, затем печатает путь бэкапа и точную команду отката. GitHub не изменяется.

Источники: [Linux MemAvailable](https://www.kernel.org/doc/html/latest/filesystems/proc.html), [Node.js statfs](https://nodejs.org/api/fs.html#statfsbavail).
